<rubric>Ѹ҆ме́ршꙋ дїа́конꙋ, и҆лѝ мона́хꙋ, и҆лѝ мїрско́мꙋ, чте́мъ ѱалти́рь над̾ тѣ́ломъ є҆гѡ̀ до погребе́нїѧ, кромѣ̀ паннѷхі́дъ и҆ лїті́й при гро́бѣ, и҆ па́ки по погребе́нїи въ па́мѧть ѹ҆сопшаго.</rubric>

<rubric>Чте́мъ же си́це. Пред̾ ко́еюждо каѳі́смою глаго́лемъ:</rubric>

{% transcludeSection "service/horologion/12.md", "pp" %}

<rubric>По ко́ейждо Сла́вѣ чте́мъ мл҃твꙋ: <a href="/canons/deceasedman/#h-3af26f95" target="_blank"><incipit><red>П</red>омѧнѝ, гдⷭ҇и бж҃е на́шъ:</incipit></a>, помина́юще ѹ҆со́пшаго. По сконча́нїи же каѳі́смы чте́мъ <incipit><red>Трист҃о́е,</red></incipit> по <incipit><red>Ѻ҆́</red>ч҃е на́шъ:</incipit> та́же тропари̑ покѡ́йны: <a href="/canons/deceasedman/#h-522166b6" target="_blank"><incipit><red>С</red>о дꙋ́хи првⷣныхъ:</incipit></a>, и҆ мл҃твꙋ по каѳі́смѣ.</rubric>

<rubric>Всѧ̑ сїѧ̑ да соверша́етъ всѧ́къ бл҃гочтⷭ҇и́вый хрⷭ҇тїа́нинъ.</rubric>
