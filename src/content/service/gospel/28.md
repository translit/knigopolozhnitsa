# Є҆ѵⷢ҇лїа ѻ҆́бща свѧты̑мъ, и҆̀мже є҆гда̀ твори́мъ слꙋ́жбꙋ.

<rubric class="inline">Слꙋ́жба прест҃ы́ѧ бцⷣы.</rubric> На ѹ҆́трени є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz4" target="_blank">д҃</a>. На лїтꙋргі́и є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz54" target="_blank">н҃д</a>.

<rubric class="inline">Слꙋ́жба ст҃ы́хъ нбⷭ҇ныхъ безпло́тныхъ си́лъ.</rubric> Є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz51" target="_blank">н҃а</a>, и҆лѝ матѳе́а, зача́ло <a href="/service/gospel/8/#mtz52" target="_blank">н҃в</a>.

<rubric class="inline">Слꙋ́жба ст҃ы́хъ проро́кѡвъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz96" target="_blank">ч҃ѕ</a>, и҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz62" target="_blank">ѯ҃в</a>.

<rubric class="inline">Слꙋ́жба ст҃ы́хъ а҆пⷭ҇лѡвъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе а҆пⷭ҇ла є҆ди́нагѡ, матѳе́а, зача́ло <a href="/service/gospel/8/#mtz34" target="_blank">л҃д</a>. А҆пⷭ҇лѡмъ ѻ҆́бще, є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz50" target="_blank">н҃</a> и҆лѝ <a href="/service/gospel/19/#lkz51" target="_blank">н҃а</a>.

<rubric class="inline">Слꙋ́жба ст҃и́телѧ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz36" target="_blank">л҃ѕ</a>.

<rubric class="inline">Слꙋ́жба ст҃и́телей ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz11" target="_blank">а҃і</a>, и҆лѝ і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz35h" target="_blank">л҃є</a> ѿ полꙋ̀.

<rubric class="inline">Слꙋ́жба прпⷣбныхъ и҆ хрⷭ҇та̀ ра́ди ю҆ро́дивыхъ.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz43" target="_blank">м҃г</a>, и҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz24" target="_blank">к҃д</a>.

<rubric class="inline">Слꙋ́жба мꙋ́ченика ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz63" target="_blank">ѯ҃г</a>, и҆лѝ і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz52" target="_blank">н҃в</a>.

<rubric class="inline">Слꙋ́жба мꙋ́ченикѡвъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz36" target="_blank">л҃ѕ</a>, и҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz106" target="_blank">р҃ѕ</a>.

<rubric class="inline">Слꙋ́жба сщ҃енномꙋ́ченика ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz67" target="_blank">ѯ҃з</a>.

<rubric class="inline">Слꙋ́жба сщ҃енномꙋ́ченикѡвъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz24" target="_blank">к҃д</a>, и҆лѝ <a href="/service/gospel/19/#lkz52" target="_blank">н҃в</a>, и҆лѝ <a href="/service/gospel/19/#lkz77" target="_blank">ѻ҃з</a>.

<rubric class="inline">Слꙋ́жба прпⷣбномꙋ́ченикѡвъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе преподобномꙋ́ченикꙋ є҆ди́номꙋ, ма́рка, зача́ло <a href="/service/gospel/14/#mkz37" target="_blank">л҃з</a>. Прпⷣбномꙋ́ченикѡмъ, є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz38" target="_blank">л҃и</a>. И҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz64" target="_blank">ѯ҃д</a>.

<rubric class="inline">Слꙋ́жба ст҃ы́хъ мꙋ́ченицъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz62" target="_blank">ѯ҃в</a>, и҆лѝ ма́рка, зача́ло <a href="/service/gospel/14/#mkz21" target="_blank">к҃а</a>.

<rubric class="inline">Слꙋ́жба прпⷣбныхъ же́нъ ѻ҆́бща.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz104" target="_blank">р҃д</a>, и҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz33" target="_blank">л҃г</a>.

<rubric class="inline">Слꙋ́жба и҆сповѣ́дникѡвъ.</rubric> Є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz64" target="_blank">ѯ҃д</a>.

<rubric class="inline">Слꙋ́жба безме́здникѡвъ.</rubric> Є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz34" target="_blank">л҃д</a>.



# Є҆ѵⷢ҇лїа за ѹ҆поко́й по всѧ̀ днѝ.

<rubric class="inline">Въ понедѣ́льникъ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz15" target="_blank">є҃і</a>.

<rubric class="inline">Во вто́рникъ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz16" target="_blank">ѕ҃і</a>.

<rubric class="inline">Въ сре́дꙋ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz21" target="_blank">к҃а</a>.

<rubric class="inline">Въ четверто́къ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz22" target="_blank">к҃в</a>.

<rubric class="inline">Въ пѧто́къ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz23" target="_blank">к҃г</a>.

<rubric class="inline">Въ сꙋббѡ́тꙋ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz16" target="_blank">ѕ҃і</a>.
