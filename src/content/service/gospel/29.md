# Є҆ѵⷢ҇лїа на всѧ́кꙋ потре́бꙋ разли̑чнаѧ.

<rubric>Є҆ѵⷢ҇лїа на ѡ҆свѧще́нїе є҆ле́а, се́дмь і҆ере́євъ:</rubric>

<rubric class="inline">Пе́рвый і҆ере́й:</rubric> є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz53" target="_blank">н҃г</a>.

<rubric class="inline">Вторы́й і҆ере́й:</rubric> є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz94" target="_blank">ч҃д</a>.

<rubric class="inline">Тре́тїй і҆ере́й:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz34h" target="_blank">л҃д</a> ѿ полꙋ̀.

<rubric class="inline">Четве́ртый і҆ере́й:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz26" target="_blank">к҃ѕ</a>.

<rubric class="inline">Пѧ́тый і҆ере́й:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz104" target="_blank">р҃д</a>.

<rubric class="inline">Шесты́й і҆ере́й:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz62" target="_blank">ѯ҃в</a>.

<rubric class="inline">Седмы́й і҆ере́й:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz30" target="_blank">л҃</a>.



<rubric class="inline">А҆́ѵгꙋста въ а҆ де́нь, на ѡ҆свѧще́нїе воды̀:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz14" target="_blank">д҃і</a>.

<rubric class="inline">На ѡ҆свѧще́нїе це́ркве:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz37h" target="_blank">л҃з</a> ѿ полꙋ̀.

<rubric class="inline">На ѡ҆снова́нїе и҆ на ѡ҆бновле́нїе гра́да:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz67" target="_blank">ѯ҃з</a>.

<rubric class="inline">Во вре́мѧ бездо́ждїѧ:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz65" target="_blank">ѯ҃є</a>.

<rubric class="inline">Во вре́мѧ безве́дрїѧ:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz20h" target="_blank">к҃</a> ѿ полꙋ̀.

<rubric class="inline">Въ стра́хъ трꙋ́са:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz27" target="_blank">к҃з</a>.

<rubric class="inline">Во вре́мѧ ꙗ҆́звъ:</rubric> є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz16" target="_blank">ѕ҃і</a>.

<rubric class="inline">Во ѻ҆бщенꙋ́ждїи:</rubric> є҆ѵⷢ҇лїе ма́рка, зача́ло <a href="/service/gospel/14/#mkz51" target="_blank">н҃а</a>.

<rubric class="inline">Въ наше́ствїи ва̑рваръ:</rubric> є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz70" target="_blank">ѻ҃</a>.

<rubric class="inline">Во ѹ҆мире́нїи и҆ соедине́нїи правосла́вныѧ вѣ́ры:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz20h" target="_blank">к҃</a> ѿ полꙋ̀.

<rubric class="inline">Ѡ҆ ѹ҆мире́нїи и҆ соедине́нїи це́ркве:</rubric> є҆ѵⷢ҇лїе ма́рка, зача́ло <a href="/service/gospel/14/#mkz51" target="_blank">н҃а</a>.

<rubric class="inline">За творѧ́щихъ ми́лостыню:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz20h" target="_blank">к҃</a> ѿ полꙋ̀.

<rubric class="inline">Въ запале́нїи ѻ҆гнѧ̀:</rubric> є҆ѵⷢ҇лїе лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz69" target="_blank">ѯ҃ѳ</a>.



<rubric>Над̾ болѧ́щимъ:</rubric>

<rubric class="inline">Пе́рвое:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz26" target="_blank">к҃ѕ</a>.

<rubric class="inline">Второ́е:</rubric> є҆ѵⷢ҇лїе ма́рка, зача́ло <a href="/service/gospel/14/#mkz21" target="_blank">к҃а</a>.

<rubric class="inline">Тре́тїе:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz13" target="_blank">г҃і</a>.



<rubric class="inline">На постриже́нїе мона́хѡвъ:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz39" target="_blank">л҃ѳ</a>.

<rubric class="inline">За всѧ́ко проше́нїе:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz20h" target="_blank">к҃</a> ѿ полꙋ̀. И҆лѝ ма́рка, зача́ло <a href="/service/gospel/14/#mkz51" target="_blank">н҃а</a>. И҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz88" target="_blank">п҃и</a>.

<rubric class="inline">На креще́нїе человѣ́кѡвъ:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz116" target="_blank">рѕ҃і</a>.

<rubric class="inline">Во вре́мѧ бра́ка:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz6" target="_blank">ѕ҃</a>.

<rubric class="inline">И҆сповѣ́данїю:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz1" target="_blank">а҃</a>. И҆лѝ лꙋкѝ, зача́ло <a href="/service/gospel/19/#lkz78" target="_blank">ѻ҃и</a>.

<rubric class="inline">Же́нъ и҆сповѣ́данїю:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz28" target="_blank">к҃и</a>.

<rubric class="inline">Над̾ и҆мꙋ́щимъ дꙋ́хъ недꙋ́га:</rubric> є҆ѵⷢ҇лїе матѳе́а, зача́ло <a href="/service/gospel/8/#mtz28" target="_blank">к҃и</a>, и҆лѝ <a href="/service/gospel/8/#mtz72" target="_blank">ѻ҃в</a>. И҆лѝ ма́рка, зача́ло <a href="/service/gospel/14/#mkz19" target="_blank">ѳ҃і</a>, и҆лѝ <a href="/service/gospel/14/#mkz40" target="_blank">м҃</a>. И҆лѝ лꙋкѝ, <a href="/service/gospel/19/#lkz46" target="_blank">м҃ѕ</a>.

<rubric class="inline">На погребе́нїе мїрѧ́нъ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz16" target="_blank">ѕ҃і</a>.

<rubric class="inline">На погребе́нїе мона́хѡвъ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz16" target="_blank">ѕ҃і</a>.



<rubric>На погребе́нїе і҆ере́євъ:</rubric>

<rubric class="inline">Пе́рвое:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz16" target="_blank">ѕ҃і</a>.

<rubric class="inline">Второ́е:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz15" target="_blank">є҃і</a>.

<rubric class="inline">Тре́тїе:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz21" target="_blank">к҃а</a>.

<rubric class="inline">Четве́ртое:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz22" target="_blank">к҃в</a>.

<rubric class="inline">Пѧ́тое:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz23" target="_blank">к҃г</a>.



<rubric class="inline">На погребе́нїе младе́нцєвъ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz21" target="_blank">к҃а</a>.

<rubric class="inline">Послѣ́дованїе въ ми́ръ:</rubric> є҆ѵⷢ҇лїе і҆ѡа́нна, зача́ло <a href="/service/gospel/24/#jnz48h" target="_blank">м҃и</a> ѿ полꙋ̀.

<rubric class="centered">Коне́цъ, и҆ бг҃ꙋ сла́ва.</rubric>
