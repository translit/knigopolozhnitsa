# Мѣ́сѧцъ а҆прі́лїй.

<rubric class="inline dt">а҃</rubric> <rubric class="inline dl">[з]</rubric> <red>П</red>реподо́бныѧ мт҃ре на́шеѧ марі́и є҆гѵ́птѧныни: <red>И҆</red> преподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ є҆ѵѳѵ́мїа, сꙋ́ждальскагѡ чꙋдотво́рца: <rubric class="inline">Прокі́менъ, гла́съ з҃:</rubric> <red>Ч</red>естна̀ пред̾ гдⷭ҇емъ сме́рть преподо́бныхъ є҆гѡ̀. <rubric class="inline">Сті́хъ:</rubric> <red>Ч</red>то̀ возда́мъ гдⷭ҇ви ѡ҆ всѣ́хъ, ꙗ҆̀же воздаде́ ми; <rubric class="inline">А҆пⷭ҇лъ къ гала́тѡмъ, зача́ло <a href="/service/apostle/16/#z213" target="_blank">сг҃і</a>. А҆ллилꙋ́їа, гла́съ ѕ҃:</rubric> <red>Б</red>лаже́нъ мꙋ́жъ боѧ́йсѧ гдⷭ҇а. <rubric class="inline">Сті́хъ:</rubric> <red>С</red>и́льно на землѝ бꙋ́детъ сѣ́мѧ є҆гѡ̀. <rubric class="inline">Прича́стный:</rubric> <red>В</red>ъ па́мѧть вѣ́чнꙋю:

<rubric class="inline dt">в҃</rubric> <rubric class="inline dl">[ѕ]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ и҆ чꙋдотво́рца ті́та.

<rubric class="inline dt">г҃</rubric> <rubric class="inline dl">[є]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ и҆ и҆сповѣ́дника нїки́ты, и҆гꙋ́мена ѻ҆би́тели мидїкі́йскїѧ.

<rubric class="inline dt">д҃</rubric> <rubric class="inline dl">[д]</rubric> <red>П</red>реподо́бныхъ ѻ҆ц҃ъ на́шихъ, і҆ѡ́сифа пѣснопи́сца, и҆ геѡ́ргїа и҆́же въ мале́и.

<rubric class="inline dt">є҃</rubric> <rubric class="inline dl">[г]</rubric> <red>С</red>т҃ы́хъ мꙋ́чєникъ, ѳеодꙋ́ла и҆ а҆гаѳопо́да, и҆ и҆̀же съ ни́ми.

<rubric class="inline dt">ѕ҃</rubric> <rubric class="inline dl">[в]</rubric> <red>И҆́</red>же во свѧты́хъ ѻ҆ц҃а̀ на́шегѡ є҆ѵтѷхі́а, а҆рхїепі́скопа кѡнстантїнопо́льскагѡ. <red>И҆</red> и҆́же во ст҃ы́хъ ѻ҆ц҃а̀ на́шегѡ меѳо́дїа, а҆рхїепⷭ҇кпа мора́вскагѡ.

<rubric class="inline dt">з҃</rubric> <rubric class="inline dl">[а]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ геѡ́ргїа, є҆пⷭ҇кпа мелїті́нскагѡ.

<rubric class="inline dt">и҃</rubric> <rubric class="inline dl">[з]</rubric> <red>С</red>ті́хъ а҆по́стѡлъ, и҆рѡдїѡ́на, а҆га́ва, рꙋ́фа, и҆ и҆̀же съ ни́ми

<rubric class="inline dt">ѳ҃</rubric> <rubric class="inline dl">[ѕ]</rubric> <red>С</red>т҃а́гѡ мꙋ́ченика є҆ѵѱѷхі́а.

<rubric class="inline dt">і҃</rubric> <rubric class="inline dl">[є]</rubric> <red>С</red>т҃ы́хъ мꙋ́чєникъ, тере́нтїа и҆ помпиі́а, и҆ и҆̀же съ ни́ми.

<rubric class="inline dt">а҃і</rubric> <rubric class="inline dl">[д]</rubric> <red>С</red>т҃а́гѡ сщ҃енномꙋ́ченика а҆нтѵ́пы, є҆пⷭ҇кпа перга́ма а҆сі́йскагѡ.

<rubric class="inline dt">в҃і</rubric> <rubric class="inline dl">[г]</rubric> <red>С</red>т҃а́гѡ сщ҃енномꙋ́ченика и҆ и҆сповѣ́дника васі́лїа, є҆пі́скопа парі́йскагѡ.

<rubric class="inline dt">г҃і</rubric> <rubric class="inline dl">[в]</rubric> <red>С</red>т҃а́гѡ сщ҃енномꙋ́ченика а҆рте́мѡна.

<rubric class="inline dt">д҃і</rubric> <rubric class="inline dl">[а]</rubric> <red>И҆́</red>же во ст҃ы́хъ ѻ҆ц҃а̀ на́шегѡ и҆ и҆сповѣ́дника марті́на, па́пы ри́мскагѡ.

<rubric class="inline dt">є҃і</rubric> <rubric class="inline dl">[з]</rubric> <red>С</red>т҃ы́хъ а҆по́стѡлъ, а҆рїста́рха, пꙋ́да и҆ трофі́ма.

<rubric class="inline dt">ѕ҃і</rubric> <rubric class="inline dl">[ѕ]</rubric> <red>С</red>т҃ы́хъ мꙋ́ченицъ, і҆ри́ны, а҆га́пїи и҆ хїоні́и.

<rubric class="inline dt">з҃і</rubric> <rubric class="inline dl">[є]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ сѷмеѡ́на персі́дскагѡ: <red>И҆</red> преподо́бнагѡ а҆ка́кїа, є҆пі́скопа мелїті́нскагѡ: <red>И҆</red> преставле́нїе преподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ зѡсі́мы и҆гꙋ́мена, солове́цкагѡ чꙋдотво́рца. <rubric class="inline">Прокі́менъ, гла́съ з҃:</rubric> <red>Ч</red>естна̀ пред̾ гдⷭ҇емъ сме́рть преподо́бныхъ є҆гѡ̀. <rubric class="inline">Сті́хъ:</rubric> <red>Ч</red>то̀ возда́мъ гдⷭ҇ви ѡ҆ всѣ́хъ, ꙗ҆̀же воздаде́ ми; <rubric class="inline">А҆пⷭ҇лъ къ гала́тѡмъ, зача́ло <a href="/service/apostle/16/#z213" target="_blank">сг҃і</a>. А҆ллилꙋ́їа, гла́съ ѕ҃:</rubric> <red>Б</red>лаже́нъ мꙋ́жъ боѧ́йсѧ гдⷭ҇а. <rubric class="inline">Сті́хъ:</rubric> <red>С</red>и́льно на землѝ бꙋ́детъ сѣ́мѧ є҆гѡ̀. <rubric class="inline">Прича́стный:</rubric> <red>В</red>ъ па́мѧть вѣ́чнꙋю:

<rubric class="inline dt">и҃і</rubric> <rubric class="inline dl">[д]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ і҆ѡа́нна, ѹ҆ченика̀ ст҃а́гѡ григо́рїа декаполі́та.

<rubric class="inline dt">ѳ҃і</rubric> <rubric class="inline dl">[г]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ і҆ѡа́нна ветхопеще́рника.

<rubric class="inline dt">к҃</rubric> <rubric class="inline dl">[в]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ ѳео́дѡра трїхи́ны.

<rubric class="inline dt">к҃а</rubric> <rubric class="inline dl">[а]</rubric> <red>С</red>т҃а́гѡ сщ҃енномꙋ́ченика і҆аннꙋа́рїа, и҆ дрꙋжи́ны є҆гѡ̀: <red>И҆</red> ст҃а́гѡ сщ҃енномꙋ́ченика ѳео́дѡра, и҆́же въ пергі́и.

<rubric class="inline dt">к҃в</rubric> <rubric class="inline dl">[з]</rubric> <red>П</red>реподо́бнагѡ ѻ҆ц҃а̀ на́шегѡ ѳео́дѡра сѷкеѡ́та: <red>И҆</red> пренесе́нїе моще́й ст҃а́гѡ благовѣ́рнагѡ кн҃зѧ все́волода, нарече́ннагѡ во ст҃о́мъ креще́нїи гаврїи́ла.

<rubric class="inline dt">к҃г</rubric> <rubric class="inline dl">[ѕ]</rubric> <red>С</red>т҃а́гѡ сла́внагѡ великомꙋ́ченика, побѣдоно́сца и҆ чꙋдотво́рца геѡ́ргїа: <red>И҆</red> ст҃ы́ѧ мꙋ́ченицы цр҃и́цы а҆леѯа́ндры. <rubric class="inline">Прокі́менъ пра́здника, и҆ ст҃а́гѡ, гла́съ з҃:</rubric> <red>В</red>озвесели́тсѧ пра́ведникъ ѡ҆ гдⷭ҇ѣ, и҆ ѹ҆пова́етъ на него̀. <rubric class="inline">Сті́хъ:</rubric> <red>Ѹ҆</red>слы́ши бж҃е гла́съ мо́й, внегда̀ моли́ти ми сѧ къ тебѣ̀. <rubric class="inline">А҆по́столъ дѣѧ́нїй, зача́ло <a href="/service/apostle/5/#z29" target="_blank">к҃ѳ</a>. Прича́стенъ пра́здника, и҆ ст҃а́гѡ:</rubric> <red>В</red>ъ па́мѧть вѣ́чнꙋю бꙋ́детъ пра́ведникъ:

<rubric class="inline dt">к҃д</rubric> <rubric class="inline dl">[є]</rubric> <red>С</red>т҃а́гѡ мꙋ́ченика са́ввы стратила́та.

<rubric class="inline dt">к҃є</rubric> <rubric class="inline dl">[д]</rubric> <red>С</red>т҃а́гѡ а҆по́стола и҆ є҆ѵⷢ҇лі́ста ма́рка. <rubric class="inline">Прокі́менъ, гла́съ и҃:</rubric> <red>В</red>о всю̀ зе́млю и҆зы́де вѣща́нїе и҆́хъ, и҆ въ концы̀ вселе́нныѧ гл҃ы и҆́хъ. <rubric class="inline">Сті́хъ:</rubric> <red>Н</red>б҃са̀ повѣ́даютъ сла́вꙋ бж҃їю: <rubric class="inline">А҆пⷭ҇лъ ѡ҆ петро́ва посла́нїѧ, зача́ло <a href="/service/apostle/7/#z63" target="_blank">ѯ҃г</a>. <rubric class="inline dt">к҃з</rubric> <rubric class="inline dl">[в]</rubric> <red>С</red>т҃а́гѡ сщ҃енномꙋ́ченика сѷмеѡ́на, сро́дника гдⷭ҇нѧ. <rubric class="inline">Прокі́менъ, гла́съ и҃:</rubric> <red>В</red>о всю̀ зе́млю и҆зы́де вѣща́нїе и҆́хъ, и҆ въ концы̀ вселе́нныѧ гл҃ы и҆́хъ. <rubric class="inline">Сті́хъ:</rubric> <red>Н</red>б҃са̀ повѣ́даютъ сла́вꙋ бж҃їю: <rubric class="inline"> А҆пⷭ҇лъ къ корі́нѳѧнѡмъ, зача́ло <a href="/service/apostle/14/#z131" target="_blank">рл҃а</a>.
